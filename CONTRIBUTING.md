# Contributing

Thanks for helping make personal story retrieval more useful and safer.

## Development

1. Fork and clone the repository.
2. Use Node.js 20 or newer.
3. Run `npm install`.
4. Add behavior-focused tests for changes.
5. Run `npm run check` and `npm pack --dry-run`.

Keep the vault format backwards-compatible when possible. Treat real essays as sensitive data: tests, issues, pull requests, recordings, and screenshots must use invented fixtures.

For large format or tool-contract changes, open an issue first. Small fixes and documentation improvements can go directly to a pull request.

By participating, you agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
