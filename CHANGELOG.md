# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and semantic versioning.

## [1.0.0] - 2026-09-03

### Added

- Notion ZIP, directory, Markdown, text, HTML, and CSV ingestion.
- Portable Obsidian-compatible story vault with deterministic IDs and indexes.
- Local stdio MCP search, retrieval, pagination, stats, and opt-in curation tools.
- Story Retriever skill for evidence-backed retrieval and initial curation.
- Client configuration generator, validation, documentation, tests, and CI.
